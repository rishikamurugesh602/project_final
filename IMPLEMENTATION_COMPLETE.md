## 1. EXECUTIVE SUMMARY

This academic prototype provides a real-time audio analysis and verification pipeline combining:
1. **Acoustic Deepfake Detection**: PyTorch-based CNN + GRU model analyzing spectral features.
2. **Automatic Speech Recognition**: OpenAI Whisper transcription at controlled, non-blocking intervals.
3. **NLP Scam Intent Analysis**: Rule-based keywords combined with zero-shot transformer classification.
4. **Risk Fusion Engine**: Fuses acoustic and semantic probabilities into transparent risk categories (`LOW`, `MEDIUM`, `HIGH`).
5. **In-App WebRTC Peer Calling**: In-browser browser-to-browser VoIP audio calls with room IDs, dual mutual consent enforcement, and remote track interception.
6. **Streaming & Backpressure**: Bounded sliding audio windows (3.5s max), bounded queue (10 chunks), backpressure chunk-dropping, and off-event-loop model execution.
7. **Privacy by Design**: No raw audio persisted to disk/db; in-memory decoding with guaranteed temp cleanup; analysis history purge endpoints.
8. **Protocol Validation**: Tooling for official ASVspoof 2019 dataset protocols without unpartitioned folder copying or arbitrary splits.

## 2. REPOSITORY COMPONENTS

### Core Application (`app/`)
- `app/main.py`: FastAPI application with configurable CORS, lifespan initialization, and mounted routers.
- `app/api/routes.py`: REST endpoints (`/analyze/audio`, `/analyze/transcript`, `/results`, `/history`, `/privacy`).
- `app/api/websocket.py`: Low-latency WebSocket streaming endpoint (`/api/v1/ws/analyze`).
- `app/api/live_call.py`: WebRTC signaling WebSocket (`/call/ws/...`), session endpoints, and in-browser calling UI (`/call/app`).
- `app/services/call_manager.py`: `CallSessionManager` tracking active WebRTC rooms, participants, and mutual consent flags.
- `app/services/streaming_processor.py`: `BoundedAudioBuffer` (3.5s sliding window) and `StreamingAnalysisSession` (bounded queue, backpressure handling, off-thread execution).
- `app/services/deepfake_service.py`: Pipeline orchestration returning the canonical result schema.
- `app/services/audio_processor.py`: Audio loading, normalization, silence trimming, and Mel spectrogram extraction.
- `app/services/asr_service.py`: OpenAI Whisper transcription.
- `app/services/risk_engine.py`: Weighted risk scoring and reasoning generator.
- `app/models/deepfake_detector.py`: CNN + GRU PyTorch architecture with honest `model_status` reporting.
- `app/models/scam_detector.py`: Keyword detection and zero-shot transformer with offline fallback.
- `app/models/model_manager.py`: Model lifecycle and caching.
- `app/database/database.py` & `crud.py`: SQLite ORM setup with history purge methods.
- `app/schemas/analysis.py`: Pydantic validation schemas.
- `app/utils/config.py`: Environment configuration loader.
- `app/utils/logging.py`: Structured logging.

### Frontend Dashboard (`dashboard/`)
- `dashboard/streamlit_app.py`: Interactive UI with upload analysis, WebRTC calling guidance, live metrics, probability gauges, history purge, and transparent model status disclosures.

### Training & Dataset Tools (`training/`)
- `training/validate_protocol.py`: ASVspoof protocol parsing, missing audio detection, and class counting.
- `training/dataset.py`: PyTorch dataset loader.
- `training/train_deepfake.py`: Deepfake detector training script.
- `training/evaluate_deepfake.py`: Held-out evaluation script.

### Automated Tests (`tests/`)
- `tests/test_system.py`: 15 unit and integration tests.
- `tests/test_streaming_and_webrtc.py`: 9 unit tests for sliding windows, bounded queues, backpressure, session disconnects, mutual consent, database clearing, and protocol validation.
